# Feature Specification: 声音与地图系统

**Feature Branch**: `012-sound-map-system`  
**Created**: 2025-12-13  
**Status**: Draft  
**Input**: User description: "1. 新增声音系统，包括背景音乐，动物的声音，走路，摔下来的声音等等 2. 新增地图系统，按 M 可以查看大地图，右上角也有一个圆形的实时地图，左上角的信息可以加上坐标"

## Clarifications

### Session 2025-12-13

- Q: 玩家在地下/室内时，小地图应该显示什么？ → A: 显示当前所在层级的平面图（类似 Minecraft MOD 的做法）
- Q: 音频资源从哪里获取？ → A: 使用免费开源音效库（如 freesound.org、OpenGameArt）
- Q: 多个音效同时播放时的处理策略？ → A: 简单混合（所有音效同时播放，自动混音）
- Q: 音频不可用时的降级策略？ → A: 静默降级（游戏正常运行，无音频提示）
- Q: 背景音乐在场景切换时的过渡方式？ → A: 淡入淡出过渡（旧音乐淡出，新音乐淡入）

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 背景音乐体验 (Priority: P1)

玩家进入游戏后，能够听到沉浸式的背景音乐，增强游戏氛围和沉浸感。背景音乐应该循环播放，玩家可以控制音量或静音。

**Why this priority**: 背景音乐是最基础的声音体验，能立即改善游戏的单调感，对所有玩家都有影响。

**Independent Test**: 进入游戏即可验证背景音乐是否播放，通过音量控制可验证调节功能。

**Acceptance Scenarios**:

1. **Given** 玩家启动游戏, **When** 游戏加载完成, **Then** 背景音乐自动开始播放
2. **Given** 背景音乐正在播放, **When** 玩家调整音量滑块, **Then** 音乐音量相应变化
3. **Given** 背景音乐正在播放, **When** 玩家点击静音按钮, **Then** 所有声音静音，图标显示静音状态

---

### User Story 2 - 移动音效反馈 (Priority: P1)

玩家在游戏中移动时能听到脚步声，不同地形可能有不同的脚步声效果，增强移动的真实感。

**Why this priority**: 走路是玩家最频繁的操作，脚步声能显著提升操作反馈和沉浸感。

**Independent Test**: 控制角色移动即可验证脚步声是否播放。

**Acceptance Scenarios**:

1. **Given** 玩家角色站立不动, **When** 玩家按下移动键开始行走, **Then** 播放脚步声音效
2. **Given** 玩家角色正在移动, **When** 玩家停止移动, **Then** 脚步声停止播放
3. **Given** 玩家角色正在奔跑, **When** 持续移动, **Then** 脚步声节奏加快

---

### User Story 3 - 实时小地图导航 (Priority: P1)

玩家在游戏过程中，右上角显示一个圆形的实时小地图，帮助玩家了解周围环境和方向。

**Why this priority**: 小地图是持续可见的导航工具，对玩家定位和探索至关重要。

**Independent Test**: 进入游戏即可看到右上角小地图，移动时小地图实时更新。

**Acceptance Scenarios**:

1. **Given** 玩家在游戏中, **When** 查看屏幕右上角, **Then** 显示圆形实时小地图
2. **Given** 小地图显示中, **When** 玩家移动位置, **Then** 小地图实时更新显示新位置
3. **Given** 小地图显示中, **When** 玩家转向, **Then** 小地图相应旋转或指示方向变化

---

### User Story 4 - 坐标信息显示 (Priority: P1)

玩家在左上角信息区域可以看到当前位置的坐标，方便定位和分享位置。

**Why this priority**: 坐标显示是基础的位置信息，实现简单但对玩家导航非常有用。

**Independent Test**: 进入游戏查看左上角即可验证坐标显示，移动时坐标数值变化。

**Acceptance Scenarios**:

1. **Given** 玩家在游戏中, **When** 查看左上角信息区域, **Then** 显示当前 X、Y、Z 坐标
2. **Given** 坐标显示中, **When** 玩家移动位置, **Then** 坐标数值实时更新

---

### User Story 5 - 大地图查看 (Priority: P2)

玩家按 M 键可以打开全屏大地图，查看更大范围的地形和已探索区域。

**Why this priority**: 大地图是辅助导航功能，相比小地图使用频率较低，但对长距离规划重要。

**Independent Test**: 按 M 键即可验证大地图是否打开，再按可关闭。

**Acceptance Scenarios**:

1. **Given** 玩家在游戏中, **When** 按下 M 键, **Then** 打开全屏大地图界面
2. **Given** 大地图已打开, **When** 再次按下 M 键或 ESC 键, **Then** 关闭大地图返回游戏
3. **Given** 大地图已打开, **When** 查看地图, **Then** 显示玩家当前位置标记
4. **Given** 大地图已打开, **When** 使用鼠标滚轮, **Then** 可以缩放地图视图

---

### User Story 6 - 摔落音效 (Priority: P2)

玩家从高处摔落着地时，播放摔落音效，提供落地反馈。

**Why this priority**: 摔落是常见但非持续性的游戏事件，音效能增强危险感知。

**Independent Test**: 从高处跳下着地即可验证摔落音效。

**Acceptance Scenarios**:

1. **Given** 玩家从一定高度下落, **When** 着地时, **Then** 播放摔落着地音效
2. **Given** 玩家从较高处下落, **When** 着地时, **Then** 摔落音效更响亮或不同

---

### User Story 7 - 动物声音 (Priority: P3)

游戏中的动物会发出相应的声音，增加世界的生动感。

**Why this priority**: 动物声音增强环境氛围，但依赖于游戏中是否有动物实体。

**Independent Test**: 接近动物即可验证是否播放动物声音。

**Acceptance Scenarios**:

1. **Given** 游戏中存在动物, **When** 玩家接近动物, **Then** 可以听到该动物的声音
2. **Given** 动物在远处, **When** 玩家靠近, **Then** 动物声音逐渐变大
3. **Given** 动物在附近, **When** 玩家远离, **Then** 动物声音逐渐变小

---

### Edge Cases

- 当多个声音同时播放时，系统采用简单混合策略（所有音效同时播放，自动混音）
- 当玩家快速切换场景时，背景音乐采用淡入淡出过渡
- 当玩家处于地图边界时，小地图和大地图如何显示？
- 当玩家在地下或室内时，小地图显示当前所在层级的平面图
- 当浏览器不支持音频或用户禁用音频时，游戏静默降级正常运行

## Requirements *(mandatory)*

### Functional Requirements

**声音系统**

- **FR-001**: 系统 MUST 在游戏加载完成后自动播放背景音乐
- **FR-002**: 系统 MUST 支持背景音乐循环播放
- **FR-021**: 系统 MUST 在场景切换时使用淡入淡出过渡背景音乐
- **FR-003**: 系统 MUST 提供音量调节控制（0-100%）
- **FR-004**: 系统 MUST 提供一键静音/取消静音功能
- **FR-005**: 系统 MUST 在玩家移动时播放脚步声
- **FR-006**: 系统 MUST 在玩家停止移动时停止脚步声
- **FR-007**: 系统 MUST 在玩家从高处着地时播放摔落音效
- **FR-008**: 系统 MUST 根据距离调整动物声音的音量（3D 空间音效）
- **FR-009**: 系统 MUST 支持多个音效同时播放
- **FR-010**: 系统 MUST 记住用户的音量设置（本地存储）

**地图系统**

- **FR-011**: 系统 MUST 在屏幕右上角显示圆形实时小地图
- **FR-012**: 系统 MUST 在小地图上显示玩家当前位置和朝向
- **FR-013**: 系统 MUST 实时更新小地图内容
- **FR-020**: 系统 MUST 根据玩家所在高度层级自动切换小地图显示内容（地表/地下）
- **FR-014**: 系统 MUST 在左上角信息区域显示玩家坐标（X, Y, Z）
- **FR-015**: 系统 MUST 实时更新坐标显示
- **FR-016**: 系统 MUST 在玩家按 M 键时打开全屏大地图
- **FR-017**: 系统 MUST 在玩家按 M 键或 ESC 键时关闭大地图
- **FR-018**: 系统 MUST 在大地图上显示玩家当前位置标记
- **FR-019**: 系统 MUST 支持大地图缩放功能

### Key Entities

- **AudioManager**: 管理所有游戏音频，包括背景音乐、音效的播放、暂停、音量控制
- **SoundEffect**: 表示单个音效，包含音频源、音量、是否循环等属性
- **MiniMap**: 右上角小地图组件，显示周围环境的俯视图
- **WorldMap**: 全屏大地图组件，显示整个世界的概览
- **PlayerPosition**: 玩家位置信息，包含 X、Y、Z 坐标

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 玩家进入游戏后 2 秒内能听到背景音乐
- **SC-002**: 音量调节响应时间小于 100 毫秒
- **SC-003**: 脚步声与玩家移动动作同步，延迟不超过 50 毫秒
- **SC-004**: 小地图刷新率至少 10 帧/秒，保持流畅显示
- **SC-005**: 坐标显示实时更新，延迟不超过 100 毫秒
- **SC-006**: 按 M 键后大地图在 500 毫秒内完全显示
- **SC-007**: 90% 的玩家能够成功使用音量控制功能
- **SC-008**: 90% 的玩家能够成功打开和关闭大地图

## Assumptions

- 游戏已有玩家移动系统，可以获取移动状态和速度
- 游戏已有玩家位置系统，可以获取 X、Y、Z 坐标
- 浏览器支持 Web Audio API
- 音频资源使用免费开源音效库（freesound.org、OpenGameArt 等）
- 左上角已有信息显示区域，可以扩展添加坐标
- 游戏世界有明确的坐标系统
