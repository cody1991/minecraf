# Feature Specification: 水下显示优化

**Feature Branch**: `007-underwater-display`  
**Created**: 2025-12-12  
**Status**: Draft  
**Input**: User description: "优化水下的展示（现在很奇怪）。需要填充完整"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 水体完整填充显示 (Priority: P1)

玩家在探索世界时，看到的水体应该是完整连续的，没有空洞或缺失的水方块。当前水体在某些区域显示不完整，看起来有"洞"或断层。

**Why this priority**: 这是用户明确提出的核心问题 - 水需要"填充完整"。不完整的水体严重影响游戏的视觉真实感和沉浸体验。

**Independent Test**: 可以通过在水域附近移动观察水体是否连续无缺口来独立测试。

**Acceptance Scenarios**:

1. **Given** 玩家站在水域附近, **When** 观察水面和水下区域, **Then** 水体应该完整连续，没有可见的空洞或缺失方块
2. **Given** 玩家在水下游泳, **When** 环顾四周, **Then** 周围的水方块应该完整填充，不应看到"透视"到远处的情况
3. **Given** 水域与地形交界处, **When** 观察边界, **Then** 水应该正确填充到水平面高度，与地形无缝衔接

---

### User Story 2 - 水下视觉效果改善 (Priority: P2)

玩家潜入水下时，应该有明显的水下视觉反馈，包括蓝色色调滤镜和适当的能见度限制，让玩家清楚知道自己在水中。

**Why this priority**: 水下视觉效果是提升沉浸感的重要元素，但优先级低于基础的水体完整性问题。

**Independent Test**: 可以通过让玩家潜入水下并观察屏幕效果来独立测试。

**Acceptance Scenarios**:

1. **Given** 玩家头部在水面以上, **When** 观察场景, **Then** 场景显示正常，无水下效果
2. **Given** 玩家头部潜入水下, **When** 观察场景, **Then** 屏幕应呈现蓝色色调，表示在水下
3. **Given** 玩家在水下, **When** 观察远处物体, **Then** 16格以外的物体应逐渐衰减不可见，模拟水下能见度限制

---

### User Story 3 - 水面渲染优化 (Priority: P3)

水面应该有适当的视觉表现，能够清晰区分水面与水下，提供良好的视觉层次感。

**Why this priority**: 水面效果是锦上添花的功能，在基础水体显示正确后再优化。

**Independent Test**: 可以通过从水面上方观察水体来独立测试。

**Acceptance Scenarios**:

1. **Given** 玩家在水面上方, **When** 向下观察水面, **Then** 水面应该有适当的透明度，能看到水下内容
2. **Given** 玩家接近水面, **When** 观察水面边缘, **Then** 水面与空气的边界应该清晰可辨

---

### Edge Cases

- 水与玻璃等其他透明方块相邻时的渲染顺序
- 单个水方块的显示（孤立的水源）
- 水域边缘（只有一格深的浅水区）
- 玩家快速进出水面时的效果切换
- 极深水域的渲染性能

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统必须确保水平面以下、地形以上的所有空间都被水方块填充
- **FR-002**: 系统必须正确渲染相邻水方块之间的面（内部面不应显示）
- **FR-003**: 系统必须在玩家头部浸入水中时应用水下视觉效果
- **FR-004**: 系统必须在玩家头部离开水面时移除水下视觉效果
- **FR-005**: 水下视觉效果必须包含蓝色色调滤镜
- **FR-006**: 水方块必须保持半透明特性，允许看到水下的方块
- **FR-007**: 系统必须正确处理水与其他透明方块（如玻璃）的渲染顺序

### Key Entities

- **Water Block**: 水方块，具有透明属性，无碰撞体积，用于填充水域
- **Player Submerged State**: 玩家头部是否在水下的状态，用于触发水下效果
- **Underwater Effect**: 水下视觉效果，包括色调滤镜和雾效果

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 玩家在任意水域观察时，水体连续无空洞的比例达到 100%
- **SC-002**: 玩家潜入水下后，水下视觉效果在 0.1 秒内生效
- **SC-003**: 玩家离开水面后，水下视觉效果在 0.1 秒内消失
- **SC-004**: 水域渲染不造成明显帧率下降（与陆地区域相比帧率差异不超过 10%）
- **SC-005**: 90% 的玩家能够通过视觉效果立即识别自己是否在水下

## Assumptions

- 当前水平面高度（WATER_LEVEL = 59）保持不变
- 水方块的透明度设置（opacity: 0.6）可以根据需要调整
- 水下效果使用后处理滤镜实现，不需要修改基础渲染管线
- 性能优化不在本功能范围内，但需确保不引入明显性能问题
- 水下能见度距离为 16 格（256 像素），超出此距离的物体逐渐衰减

## Clarifications

### Session 2025-12-12

- Q: 水下能见度距离应为多少？ → A: 中等距离（16格）
