# Feature Specification: 修复动物浮空问题

**Feature Branch**: `016-fix-animal-spawning`  
**Created**: 2025-12-13  
**Status**: Draft  
**Input**: User description: "修复动物浮空问题 - 动物生成位置计算需要优化，确保生成在地面上"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 动物正确生成在地面上 (Priority: P1)

玩家在游戏世界中探索时，看到的所有动物都应该站在地面上，而不是悬浮在空中。这是基本的视觉正确性要求，直接影响游戏的沉浸感和真实性。

**Why this priority**: 这是核心问题，动物悬浮在空中会严重破坏游戏体验，让玩家感觉游戏有明显的 bug。

**Independent Test**: 可以通过在游戏中四处移动触发新区块加载，观察新生成的动物是否都站在地面上来独立测试。

**Acceptance Scenarios**:

1. **Given** 玩家进入一个新区块, **When** 系统生成动物, **Then** 动物的脚部应该接触地面方块顶部
2. **Given** 地形中存在洞穴（地表下方有空洞）, **When** 系统在该位置生成动物, **Then** 动物应该生成在洞穴内的实际地面上，而不是悬浮在理论地表高度
3. **Given** 地形中有树木, **When** 系统在树木附近生成动物, **Then** 动物应该生成在树下的地面上，而不是在树叶或树干上

---

### User Story 2 - 动物不在水中生成 (Priority: P1)

陆地动物（牛、羊、猪、鸡、兔子、狼、狐狸）不应该生成在水中或水面上，这违反了基本的游戏逻辑。

**Why this priority**: 陆地动物在水中生成同样是明显的视觉 bug，与浮空问题同等重要。

**Independent Test**: 可以通过在湖泊、河流附近观察是否有陆地动物生成在水中来独立测试。

**Acceptance Scenarios**:

1. **Given** 某个位置被水方块覆盖, **When** 系统尝试在该位置生成陆地动物, **Then** 系统应该跳过该位置，不生成动物
2. **Given** 某个位置的地面方块是水, **When** 系统计算生成位置, **Then** 系统应该拒绝该位置

---

### User Story 3 - 动物不卡在方块内 (Priority: P2)

动物生成后不应该卡在方块内部，应该有足够的空间站立。

**Why this priority**: 虽然不如浮空问题明显，但动物卡在方块内同样影响游戏体验。

**Independent Test**: 可以通过观察生成的动物是否有部分身体穿透方块来独立测试。

**Acceptance Scenarios**:

1. **Given** 系统找到一个地面位置, **When** 检查生成空间, **Then** 动物脚部和头部位置（地面上方 2 格）必须是非固体方块
2. **Given** 地面上方有固体方块阻挡, **When** 系统尝试生成动物, **Then** 系统应该跳过该位置

---

### Edge Cases

- 洞穴场景：当地表下方有洞穴时，理论高度和实际地面高度不一致
- 树木场景：树叶和树干是固体方块，但不应该作为动物的生成地面
- 悬崖边缘：陡峭的地形可能导致动物生成在不稳定的位置
- 深水区域：需要检测水方块并避免在其中生成陆地动物
- 半固体方块：如草丛、花朵等非固体装饰方块，动物可以生成在其中

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统必须通过向下扫描实际方块数据来确定真实地面位置，而不是仅依赖理论高度图
- **FR-002**: 系统必须检测水方块，并拒绝在水中或水面上生成陆地动物
- **FR-003**: 系统必须忽略树叶和树干方块，将它们视为非有效地面
- **FR-004**: 系统必须验证动物生成位置上方有足够的非固体空间（至少 2 格高度）
- **FR-005**: 系统必须将动物的 Y 坐标设置为地面方块顶部加上动物高度的一半
- **FR-006**: 系统应该避免在陡峭斜坡上生成动物，以提高视觉自然度

### Key Entities

- **生成位置 (Spawn Position)**: 包含世界坐标 (x, y, z)，其中 y 是经过验证的实际地面高度
- **地面方块 (Ground Block)**: 必须是固体方块，但不能是树叶或树干
- **空间检查 (Space Check)**: 验证脚部和头部位置是否为非固体、非水方块

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 100% 的新生成动物站在实际地面上，无悬浮现象
- **SC-002**: 0% 的陆地动物生成在水中或水面上
- **SC-003**: 0% 的动物卡在固体方块内部
- **SC-004**: 动物生成逻辑在各种地形（平原、山地、洞穴入口、树林）中表现一致
- **SC-005**: 生成位置计算不显著影响区块加载性能（玩家无感知的延迟）
