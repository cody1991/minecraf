# Feature Specification: 物品与背包系统

**Feature Branch**: `019-inventory-system`  
**Created**: 2025-12-16  
**Status**: Draft  
**Input**: 物品与背包系统 - 物品掉落与拾取、背包系统、快捷栏优化

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 破坏方块获得物品 (Priority: P1)

玩家在游戏中破坏方块后，方块会掉落对应的物品实体。物品实体在地面上弹跳，玩家靠近后自动拾取到背包中，并播放拾取音效。

**Why this priority**: 这是整个物品系统的基础，没有物品掉落就无法获得物品，后续的背包和快捷栏功能都依赖于此。

**Independent Test**: 可以通过破坏任意方块并观察物品掉落、弹跳动画和自动拾取来独立测试。

**Acceptance Scenarios**:

1. **Given** 玩家面对一个可破坏的方块, **When** 玩家破坏该方块, **Then** 方块消失并在原位置生成对应的物品实体
2. **Given** 物品实体刚生成, **When** 物品落到地面, **Then** 物品会有弹跳动画效果
3. **Given** 地面上有物品实体, **When** 玩家走近物品（距离小于2格）, **Then** 物品自动飞向玩家并被拾取
4. **Given** 玩家拾取物品, **When** 物品进入背包, **Then** 播放拾取音效

---

### User Story 2 - 背包管理 (Priority: P2)

玩家可以按 E 键打开背包界面，查看和管理自己拥有的所有物品。背包共有36格（9格快捷栏 + 27格存储格），支持物品堆叠（同类物品最多堆叠64个）和拖拽整理。

**Why this priority**: 背包是物品管理的核心功能，玩家需要能够查看和整理收集到的物品。

**Independent Test**: 可以通过打开背包界面、拖拽物品、堆叠物品来独立测试。

**Acceptance Scenarios**:

1. **Given** 玩家在游戏中, **When** 玩家按下 E 键, **Then** 打开背包界面，显示36格物品槽
2. **Given** 背包界面打开, **When** 玩家再次按 E 键或按 ESC 键, **Then** 关闭背包界面
3. **Given** 背包中有物品, **When** 玩家拖拽物品到另一个格子, **Then** 物品移动到目标格子
4. **Given** 玩家拾取与背包中已有物品相同的物品, **When** 现有堆叠数量小于64, **Then** 物品堆叠在一起，数量增加
5. **Given** 玩家拾取物品, **When** 背包已满且无法堆叠, **Then** 物品留在地面上不被拾取

---

### User Story 3 - 快捷栏使用 (Priority: P3)

玩家可以通过底部快捷栏快速选择和使用物品。快捷栏显示物品图标和数量，支持数字键1-9快速选择和鼠标滚轮切换当前选中的槽位。

**Why this priority**: 快捷栏优化了游戏体验，让玩家能更高效地切换和使用物品。

**Independent Test**: 可以通过使用数字键、滚轮切换快捷栏槽位来独立测试。

**Acceptance Scenarios**:

1. **Given** 游戏运行中, **When** 玩家查看屏幕底部, **Then** 显示9格快捷栏UI，包含物品图标和堆叠数量
2. **Given** 快捷栏有多个物品, **When** 玩家按数字键1-9, **Then** 切换到对应槽位
3. **Given** 快捷栏有多个物品, **When** 玩家滚动鼠标滚轮, **Then** 在快捷栏槽位间循环切换
4. **Given** 当前选中某个槽位, **When** 玩家查看快捷栏, **Then** 当前选中的槽位有高亮显示

---

### Edge Cases

- 物品实体在水中或岩浆中的行为：物品在水中缓慢下沉，在岩浆中被销毁
- 物品实体长时间未被拾取：物品实体在5分钟后自动消失
- 背包满时拾取物品：物品留在地面，不被拾取
- 拖拽物品到已有不同物品的格子：两个物品交换位置
- 拖拽部分堆叠物品：右键点击可拾取一半数量的物品
- 快捷栏滚轮边界：从第9格继续滚动回到第1格（循环）

## Requirements *(mandatory)*

### Functional Requirements

**物品掉落系统**
- **FR-001**: 系统 MUST 在方块被破坏时生成对应的物品实体
- **FR-002**: 物品实体 MUST 具有物理效果（重力、弹跳）
- **FR-003**: 物品实体 MUST 在落地时产生弹跳动画
- **FR-004**: 物品实体 MUST 在玩家靠近（2格内）时自动飞向玩家
- **FR-005**: 系统 MUST 在物品被拾取时播放拾取音效
- **FR-006**: 物品实体 MUST 在5分钟未被拾取后自动消失
- **FR-007**: 物品实体 MUST 在岩浆中被销毁

**背包系统**
- **FR-008**: 系统 MUST 提供36格背包容量（9快捷栏 + 27存储格）
- **FR-009**: 玩家 MUST 能够按 E 键打开/关闭背包界面
- **FR-010**: 背包界面 MUST 显示所有物品及其堆叠数量
- **FR-011**: 系统 MUST 支持同类物品堆叠，最大堆叠数为64
- **FR-012**: 玩家 MUST 能够拖拽物品在背包格子间移动
- **FR-013**: 系统 MUST 支持物品交换（拖拽到已有物品的格子）
- **FR-014**: 系统 MUST 在背包满时阻止拾取新物品

**快捷栏系统**
- **FR-015**: 系统 MUST 在屏幕底部显示9格快捷栏UI
- **FR-016**: 快捷栏 MUST 显示物品图标和堆叠数量
- **FR-017**: 系统 MUST 高亮显示当前选中的快捷栏槽位
- **FR-018**: 玩家 MUST 能够使用数字键1-9选择快捷栏槽位
- **FR-019**: 玩家 MUST 能够使用鼠标滚轮循环切换快捷栏槽位

### Key Entities

- **ItemEntity（物品实体）**: 掉落在世界中的物品，包含物品类型、数量、位置、速度、存在时间
- **Inventory（背包）**: 玩家的物品存储容器，包含36个物品槽位
- **ItemSlot（物品槽）**: 背包中的单个格子，包含物品类型和堆叠数量（0-64）
- **Hotbar（快捷栏）**: 背包的前9格，始终显示在屏幕底部，可快速访问

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 玩家破坏方块后，物品实体在0.1秒内生成并开始下落
- **SC-002**: 物品拾取响应时间小于0.2秒（从进入拾取范围到进入背包）
- **SC-003**: 背包界面在按下 E 键后0.3秒内完全显示
- **SC-004**: 快捷栏切换响应时间小于0.1秒（按键/滚轮到视觉反馈）
- **SC-005**: 物品堆叠正确率100%（同类物品始终正确堆叠，不同类物品不会错误堆叠）
- **SC-006**: 拖拽操作成功率100%（物品始终正确移动或交换）

## Assumptions

- 所有方块破坏后都会掉落对应的物品（1:1关系）
- 物品实体使用与方块相同的纹理/图标
- 背包数据随世界存档一起保存（使用现有的存档系统）
- 快捷栏选中状态默认为第1格
- 物品拾取范围为2格（与 Minecraft 原版一致）
- 物品实体消失时间为5分钟（300秒）
