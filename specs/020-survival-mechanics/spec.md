# Feature Specification: 生存机制

**Feature Branch**: `020-survival-mechanics`  
**Created**: 2025-12-16  
**Status**: Draft  
**Input**: User description: "生存机制 - 生命值系统（10颗心、受伤闪红屏、死亡重生）、饥饿值系统（10格、跑步跳跃消耗、影响生命恢复）、食物系统（动物掉落、恢复饥饿值）、环境伤害（摔落、溺水、岩浆、仙人掌）"

## Clarifications

### Session 2025-12-16

- Q: 动物击杀机制如何实现？ → A: 本功能实现简易击杀（玩家点击动物造成伤害，动物有生命值）
- Q: 食物种类与恢复值？ → A: 按动物类型区分：生牛肉(3)、生猪排(3)、生羊肉(2)、生鸡肉(2)、生兔肉(3)

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 生命值显示与受伤反馈 (Priority: P1)

玩家在游戏中拥有 10 颗心的生命值，受到伤害时屏幕闪红提示，生命值实时更新显示。

**Why this priority**: 生命值是生存机制的核心基础，没有生命值系统其他生存功能无法运作。

**Independent Test**: 可通过让玩家受到任意伤害（如摔落）来测试生命值减少和红屏效果。

**Acceptance Scenarios**:

1. **Given** 玩家进入游戏, **When** 游戏开始, **Then** 玩家拥有满生命值（10 颗心 / 20 点生命值）并在 UI 上显示
2. **Given** 玩家有满生命值, **When** 玩家受到 2 点伤害, **Then** 生命值减少 1 颗心，屏幕短暂闪红
3. **Given** 玩家生命值为 0, **When** 玩家死亡, **Then** 显示死亡画面并提供重生选项

---

### User Story 2 - 死亡与重生机制 (Priority: P1)

玩家生命值归零时死亡，显示死亡画面，玩家可选择重生回到出生点。

**Why this priority**: 死亡重生是生存游戏的核心循环，必须与生命值系统同时实现。

**Independent Test**: 可通过让玩家持续受伤直到死亡来测试完整的死亡重生流程。

**Acceptance Scenarios**:

1. **Given** 玩家生命值为 1 点, **When** 玩家受到 1 点或更多伤害, **Then** 玩家死亡，显示死亡画面
2. **Given** 玩家处于死亡画面, **When** 玩家点击"重生"按钮, **Then** 玩家在出生点重生，生命值和饥饿值恢复满
3. **Given** 玩家死亡, **When** 玩家重生, **Then** 玩家物品栏保留（不掉落物品）

---

### User Story 3 - 饥饿值系统 (Priority: P2)

玩家拥有 10 格饥饿值，跑步和跳跃会消耗饥饿值，饥饿值影响生命值恢复速度。

**Why this priority**: 饥饿值为生存增加资源管理维度，是食物系统的前置依赖。

**Independent Test**: 可通过让玩家持续跑步跳跃观察饥饿值下降来测试。

**Acceptance Scenarios**:

1. **Given** 玩家进入游戏, **When** 游戏开始, **Then** 玩家拥有满饥饿值（10 格 / 20 点饥饿值）并在 UI 上显示
2. **Given** 玩家有满饥饿值, **When** 玩家持续跑步, **Then** 饥饿值逐渐下降
3. **Given** 玩家有满饥饿值, **When** 玩家跳跃, **Then** 每次跳跃消耗少量饥饿值
4. **Given** 玩家饥饿值大于 18 点且生命值未满, **When** 时间流逝, **Then** 生命值缓慢恢复
5. **Given** 玩家饥饿值为 0, **When** 时间流逝, **Then** 玩家开始受到饥饿伤害（每隔一段时间扣除生命值）

---

### User Story 4 - 食物系统 (Priority: P2)

动物死亡时掉落生肉，玩家可以食用食物恢复饥饿值，不同食物恢复量不同。

**Why this priority**: 食物是恢复饥饿值的唯一途径，使饥饿值系统形成完整循环。

**Independent Test**: 可通过击杀动物获取食物并食用来测试完整流程。

**Acceptance Scenarios**:

1. **Given** 玩家击杀一只动物, **When** 动物死亡, **Then** 动物掉落对应的生肉物品
2. **Given** 玩家物品栏有食物且饥饿值未满, **When** 玩家使用食物（右键）, **Then** 食物被消耗，饥饿值恢复对应数值
3. **Given** 玩家饥饿值已满, **When** 玩家尝试使用食物, **Then** 食物不被消耗，无法进食

---

### User Story 5 - 环境伤害系统 (Priority: P3)

玩家受到各种环境伤害：摔落伤害（高度阈值）、溺水伤害、岩浆伤害、仙人掌伤害。

**Why this priority**: 环境伤害丰富游戏危险元素，但不是生存机制的核心功能。

**Independent Test**: 可通过让玩家进入各种危险环境来分别测试每种伤害类型。

**Acceptance Scenarios**:

1. **Given** 玩家从 4 格以上高度坠落, **When** 玩家落地, **Then** 玩家受到与坠落高度成正比的伤害（超过 3 格开始计算）
2. **Given** 玩家在水下, **When** 玩家氧气耗尽, **Then** 玩家开始受到溺水伤害
3. **Given** 玩家接触岩浆方块, **When** 玩家在岩浆中, **Then** 玩家持续受到高额伤害
4. **Given** 玩家接触仙人掌方块, **When** 玩家碰撞仙人掌, **Then** 玩家受到 1 点伤害

---

### Edge Cases

- 玩家在受伤动画期间再次受伤时如何处理？（应累计伤害，但受伤无敌时间内不重复触发红屏）
- 玩家在水中跳跃时饥饿值消耗如何计算？（游泳消耗应与跑步类似）
- 玩家在岩浆中死亡后物品如何处理？（物品栏保留，不掉落）
- 玩家饥饿值为 0 时受到的饥饿伤害是否会致死？（饥饿伤害最多将生命值降至 1 点，不会直接致死）
- 玩家在空中时饥饿值是否消耗？（仅跳跃动作消耗，滞空不消耗）

## Requirements *(mandatory)*

### Functional Requirements

#### 生命值系统

- **FR-001**: 系统 MUST 为玩家提供 20 点生命值（显示为 10 颗心）
- **FR-002**: 系统 MUST 在玩家受伤时减少对应生命值并触发屏幕红色闪烁效果
- **FR-003**: 系统 MUST 在玩家受伤后提供 0.5 秒无敌时间，期间不受额外伤害
- **FR-004**: 系统 MUST 在 UI 上实时显示当前生命值（心形图标）
- **FR-005**: 系统 MUST 在玩家生命值归零时触发死亡状态

#### 死亡重生系统

- **FR-006**: 系统 MUST 在玩家死亡时显示死亡画面，包含"重生"按钮
- **FR-007**: 系统 MUST 在玩家选择重生后将玩家传送至出生点
- **FR-008**: 系统 MUST 在玩家重生时恢复满生命值和满饥饿值
- **FR-009**: 系统 MUST 在玩家死亡和重生时保留物品栏内容

#### 饥饿值系统

- **FR-010**: 系统 MUST 为玩家提供 20 点饥饿值（显示为 10 格）
- **FR-011**: 系统 MUST 在玩家跑步时消耗饥饿值（每移动一定距离消耗 0.1 点）
- **FR-012**: 系统 MUST 在玩家跳跃时消耗饥饿值（每次跳跃消耗 0.2 点）
- **FR-013**: 系统 MUST 在玩家饥饿值大于 18 点且生命值未满时缓慢恢复生命值
- **FR-014**: 系统 MUST 在玩家饥饿值为 0 时每 4 秒造成 1 点饥饿伤害
- **FR-015**: 系统 MUST 确保饥饿伤害不会将生命值降至 0 以下（最低保持 1 点）
- **FR-016**: 系统 MUST 在 UI 上实时显示当前饥饿值（食物图标）

#### 动物击杀系统

- **FR-017**: 系统 MUST 支持玩家点击动物造成伤害（每次点击造成 2 点伤害）
- **FR-018**: 系统 MUST 为动物提供生命值（牛/猪/羊: 10 点，鸡/兔: 4 点）
- **FR-019**: 系统 MUST 在动物生命值归零时触发死亡并掉落对应食物

#### 食物系统

- **FR-020**: 系统 MUST 在动物死亡时掉落对应的生肉物品：
  - 牛 → 生牛肉（恢复 3 点饥饿值）
  - 猪 → 生猪排（恢复 3 点饥饿值）
  - 羊 → 生羊肉（恢复 2 点饥饿值）
  - 鸡 → 生鸡肉（恢复 2 点饥饿值）
  - 兔 → 生兔肉（恢复 3 点饥饿值）
- **FR-021**: 系统 MUST 支持玩家使用（右键）食物来恢复饥饿值
- **FR-022**: 系统 MUST 在玩家饥饿值已满时阻止进食
- **FR-023**: 系统 MUST 在进食时播放进食音效

#### 环境伤害系统

- **FR-024**: 系统 MUST 在玩家从超过 3 格高度坠落时造成摔落伤害
- **FR-025**: 系统 MUST 按公式计算摔落伤害：伤害 = (坠落高度 - 3) 点
- **FR-026**: 系统 MUST 在玩家水下氧气耗尽后每 1 秒造成 2 点溺水伤害
- **FR-027**: 系统 MUST 为玩家提供 10 秒水下氧气时间
- **FR-028**: 系统 MUST 在玩家接触岩浆时每 0.5 秒造成 4 点伤害
- **FR-029**: 系统 MUST 在玩家接触仙人掌时造成 1 点伤害

### Key Entities

- **PlayerStats**: 玩家生存状态，包含生命值、饥饿值、氧气值、无敌时间等属性
- **AnimalHealth**: 动物生命值状态（牛/猪/羊: 10 点，鸡/兔: 4 点）
- **Food**: 食物物品，包含食物类型、恢复饥饿值数量：
  - 生牛肉 (RAW_BEEF): 恢复 3 点
  - 生猪排 (RAW_PORKCHOP): 恢复 3 点
  - 生羊肉 (RAW_MUTTON): 恢复 2 点
  - 生鸡肉 (RAW_CHICKEN): 恢复 2 点
  - 生兔肉 (RAW_RABBIT): 恢复 3 点
- **DamageSource**: 伤害来源类型（摔落、溺水、岩浆、仙人掌、饥饿、玩家攻击等）
- **DeathScreen**: 死亡画面 UI 组件

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 玩家能在 UI 上清晰看到生命值和饥饿值的实时变化
- **SC-002**: 玩家受伤时红屏效果在 0.3 秒内触发并持续不超过 0.5 秒
- **SC-003**: 玩家从死亡到重生完成的操作流程不超过 3 秒
- **SC-004**: 玩家持续跑步 1 分钟后饥饿值下降可感知（约 1-2 格）
- **SC-005**: 玩家能通过击杀动物获取食物并成功恢复饥饿值
- **SC-006**: 所有 4 种环境伤害（摔落、溺水、岩浆、仙人掌）均能正确触发
- **SC-007**: 游戏帧率在生存机制运行时保持 60 FPS 以上

## Assumptions

- 出生点位置使用世界中心坐标 (0, 地面高度, 0)
- 物品栏系统已存在（来自 Feature 019 物品栏系统）
- 岩浆方块类型已存在或将作为本功能一部分添加
- 仙人掌方块类型已存在或将作为本功能一部分添加
- 跑步定义为按住 Shift 键移动（或根据现有控制方案）
- 狼和狐狸为掠食者，不掉落食物（仅牛/猪/羊/鸡/兔掉落）
