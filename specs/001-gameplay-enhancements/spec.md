# Feature Specification: 基础完善阶段 - 游戏体验增强

**Feature Branch**: `001-gameplay-enhancements`  
**Created**: 2025-12-16  
**Status**: Draft  
**Input**: 基础完善阶段四个子功能：动物动画系统、手持物品与攻击动画、挖掘系统增强、篝火与熟食

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 动物动画系统 (Priority: P1)

玩家在游戏世界中观察动物时，能看到动物具有生动的动画表现：行走时腿部摆动、站立时轻微晃动、受伤时有反馈动画、死亡时有倒地动画。动物的头部会转向玩家或移动方向，让生物看起来更加真实和有生命力。

**Why this priority**: 动物是游戏世界中最常见的交互对象，生动的动画直接提升游戏沉浸感和视觉体验，是基础完善的核心内容。

**Independent Test**: 可通过进入游戏世界观察任意动物的行为来独立测试，验证动画是否流畅自然。

**Acceptance Scenarios**:

1. **Given** 玩家在游戏世界中, **When** 观察一只正在移动的动物, **Then** 动物的腿部应随移动节奏摆动
2. **Given** 动物处于静止状态, **When** 玩家观察该动物, **Then** 动物应有轻微的站立待机动画（如呼吸起伏）
3. **Given** 玩家攻击一只动物, **When** 动物受到伤害, **Then** 动物应播放受伤反馈动画（如身体闪烁或后退）
4. **Given** 动物生命值归零, **When** 动物死亡, **Then** 动物应播放死亡倒地动画后消失
5. **Given** 玩家靠近一只动物, **When** 动物注意到玩家, **Then** 动物头部应转向玩家方向

---

### User Story 2 - 手持物品与攻击动画 (Priority: P2)

玩家在第一人称视角下能看到自己手持的物品（方块、食物、工具等），攻击时手臂会挥动，不同物品有不同的视觉效果。这让玩家的操作有直观的视觉反馈。

**Why this priority**: 手持物品显示是第一人称游戏的标准体验，攻击动画提供操作反馈，直接影响玩家的操控感。

**Independent Test**: 可通过切换快捷栏物品并进行攻击操作来独立测试，验证手持显示和动画效果。

**Acceptance Scenarios**:

1. **Given** 玩家在第一人称视角, **When** 快捷栏选中某个物品, **Then** 屏幕右下角应显示该物品的手持模型
2. **Given** 玩家手持物品, **When** 玩家进行攻击操作（左键点击）, **Then** 手臂应播放挥动攻击动画
3. **Given** 玩家手持方块, **When** 观察手持效果, **Then** 方块应以合适的角度和大小显示
4. **Given** 玩家手持食物, **When** 观察手持效果, **Then** 食物应以合适的方式显示
5. **Given** 玩家快捷栏为空, **When** 观察手持区域, **Then** 应显示空手或不显示物品

---

### User Story 3 - 挖掘系统增强 (Priority: P3)

玩家挖掘方块时能看到挖掘进度条、方块上出现裂纹动画、挖掘产生粒子效果。不同材质的方块需要不同的挖掘时间，让挖掘过程更有质感和成就感。

**Why this priority**: 挖掘是游戏核心玩法之一，增强的视觉反馈让操作更有满足感，但优先级低于动画系统和手持物品。

**Independent Test**: 可通过挖掘不同类型的方块来独立测试，验证进度条、裂纹和粒子效果。

**Acceptance Scenarios**:

1. **Given** 玩家开始挖掘一个方块, **When** 持续按住挖掘键, **Then** 应显示挖掘进度条
2. **Given** 玩家正在挖掘方块, **When** 挖掘进度增加, **Then** 方块表面应逐渐显示裂纹纹理
3. **Given** 玩家正在挖掘方块, **When** 挖掘过程中, **Then** 应产生与方块材质对应的粒子效果
4. **Given** 玩家挖掘泥土方块, **When** 与挖掘石头方块对比, **Then** 泥土的挖掘时间应明显短于石头
5. **Given** 玩家中途停止挖掘, **When** 松开挖掘键, **Then** 裂纹应消失，进度重置

---

### User Story 4 - 篝火与熟食系统 (Priority: P4)

玩家可以放置篝火方块，将生肉放在篝火上自动烤制成熟食。熟食比生食恢复更多饥饿值。篝火有火焰粒子效果，增添氛围。

**Why this priority**: 篝火系统为生存玩法增加深度，但依赖于已有的食物系统和方块系统，是锦上添花的功能。

**Independent Test**: 可通过放置篝火、放入生肉、等待烤制、食用熟食来独立测试完整流程。

**Acceptance Scenarios**:

1. **Given** 玩家拥有篝火方块, **When** 在地面放置篝火, **Then** 篝火应正确放置并显示火焰粒子效果
2. **Given** 篝火已放置, **When** 玩家将生肉放入篝火, **Then** 生肉应开始烤制过程
3. **Given** 生肉正在烤制, **When** 烤制完成, **Then** 生肉应变成对应的熟食物品
4. **Given** 玩家食用熟牛肉, **When** 与生牛肉对比, **Then** 熟牛肉恢复的饥饿值应明显高于生牛肉
5. **Given** 篝火正在燃烧, **When** 玩家观察篝火, **Then** 应看到持续的火焰粒子效果和光照

---

### Edge Cases

- 动物在水中时使用游泳动画（腿部划水），空中时保持当前动画状态
- 玩家在攻击动画播放过程中切换物品：立即切换手持显示，中断当前动画
- 挖掘过程中方块被其他因素破坏：立即停止挖掘，重置进度
- 篝火最多同时烤制4个生肉，超出时提示已满
- 玩家离开篝火区域后烤制继续进行（区块加载时）
- 雨天对篝火无影响（简化处理，不熄灭）

## Requirements *(mandatory)*

### Functional Requirements

**动物动画系统**

- **FR-001**: 系统必须为所有动物实体实现行走动画，腿部随移动摆动
- **FR-002**: 系统必须为所有动物实体实现站立待机动画
- **FR-003**: 系统必须为所有动物实体实现受伤反馈动画
- **FR-004**: 系统必须为所有动物实体实现死亡倒地动画
- **FR-005**: 动物头部必须能够转向移动方向或注意目标

**手持物品与攻击动画**

- **FR-006**: 系统必须在第一人称视角显示玩家当前手持的物品
- **FR-007**: 系统必须在玩家攻击时播放手臂挥动动画
- **FR-008**: 不同类型的物品（方块、食物、工具）必须有合适的手持显示方式
- **FR-009**: 快捷栏切换物品时手持显示必须即时更新

**挖掘系统增强**

- **FR-010**: 系统必须在挖掘过程中显示进度条
- **FR-011**: 系统必须在挖掘过程中显示方块裂纹动画（至少3个阶段）
- **FR-012**: 系统必须在挖掘过程中产生粒子效果
- **FR-013**: 不同方块类型必须有不同的基础挖掘时间
- **FR-014**: 中断挖掘时进度和裂纹必须重置

**篝火与熟食系统**

- **FR-015**: 系统必须支持篝火方块的放置和破坏
- **FR-016**: 篝火必须显示火焰粒子效果
- **FR-017**: 玩家手持生肉右键点击篝火时，生肉放入篝火开始烤制
- **FR-017a**: 篝火最多同时烤制4个生肉，每个独立计时
- **FR-017b**: 烤制完成后熟食自动弹出掉落在篝火旁边
- **FR-018**: 系统必须支持5种熟食物品（熟牛肉、熟猪排、熟羊肉、熟鸡肉、熟兔肉）
- **FR-019**: 熟食恢复的饥饿值必须高于对应的生食
- **FR-020**: 篝火必须产生光照效果

### Key Entities

- **动画状态**: 表示动物当前的动画类型（行走、站立、受伤、死亡），控制动画播放
- **手持物品模型**: 表示第一人称视角下显示的物品，包含位置、旋转、缩放属性
- **挖掘进度**: 表示当前挖掘的进度值（0-100%），关联目标方块和裂纹阶段
- **方块挖掘时间表**: 定义各种方块类型的基础挖掘时间
- **篝火方块**: 特殊方块类型，具有烤制功能和粒子效果
- **熟食物品**: 新增的5种食物物品，与生食对应，恢复值更高

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 所有7种动物（牛/猪/羊/鸡/兔/狼/狐狸）均具备完整的4种动画状态
- **SC-002**: 动物动画过渡流畅，无明显卡顿或跳帧
- **SC-003**: 第一人称手持物品在所有快捷栏物品类型上正确显示
- **SC-004**: 攻击动画在0.3秒内完成播放
- **SC-005**: 挖掘进度条准确反映挖掘进度（误差不超过5%）
- **SC-006**: 裂纹动画至少有3个可辨识的阶段
- **SC-007**: 不同方块的挖掘时间差异明显（最快与最慢相差至少3倍）
- **SC-008**: 篝火粒子效果持续稳定显示
- **SC-009**: 烤制过程在合理时间内完成（5-15秒）
- **SC-010**: 熟食饥饿值恢复量比生食高至少50%

## Clarifications

### Session 2025-12-16

- Q: 篝火交互方式？ → A: 手持生肉右键点击篝火放入
- Q: 篝火同时烤制数量？ → A: 最多同时烤制4个，独立计时
- Q: 熟食掉落方式？ → A: 烤制完成后熟食自动弹出掉落在篝火旁边

## Assumptions

- 现有动物实体系统支持动画状态扩展
- 现有渲染系统支持粒子效果
- 现有食物系统可扩展支持熟食物品
- 方块挖掘时间参考 Minecraft 原版设定进行平衡
- 篝火不会被雨水熄灭（简化处理）
- 篝火烤制范围为篝火方块上方1格
