**Status**: Draft

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 2×2 手持合成 (Priority: P1)

玩家无需任何工具，可以直接在物品栏界面中使用 2×2 合成格制作基础物品，如木板和木棍。

**Why this priority**: 这是合成系统的基础入口，玩家从零开始时必须先能制作木板和木棍，才能进一步制作工作台和工具。

**Independent Test**: 可以通过打开物品栏、放入原木到 2×2 合成格、获得木板来完整测试，无需其他系统支持。

**Acceptance Scenarios**:

1. **Given** 玩家打开物品栏界面，**When** 玩家将 1 个原木放入 2×2 合成格任意位置，**Then** 输出格显示 4 个木板
2. **Given** 玩家打开物品栏界面且合成格中有原木，**When** 玩家点击输出格的木板，**Then** 木板添加到物品栏，原木消耗 1 个
3. **Given** 玩家物品栏界面打开，**When** 玩家将 2 个木板垂直放置在 2×2 合成格，**Then** 输出格显示 4 个木棍
4. **Given** 玩家有 4 个木板在 2×2 合成格排列成正方形，**When** 玩家点击输出格，**Then** 获得 1 个工作台方块

---

### User Story 2 - 工作台放置与 3×3 合成 (Priority: P1)

玩家可以在世界中放置工作台方块，右键点击打开 3×3 合成界面，制作更复杂的物品如工具。

**Why this priority**: 工作台是进阶合成的核心，没有它玩家无法制作任何工具，游戏进程会被阻断。

**Independent Test**: 可以通过放置工作台、右键打开界面、使用 3×3 合成格制作木镐来完整测试。

**Acceptance Scenarios**:

1. **Given** 玩家手持工作台方块，**When** 玩家对着地面右键点击，**Then** 工作台方块放置在目标位置
2. **Given** 世界中存在工作台方块，**When** 玩家对准工作台右键点击（5 格内），**Then** 打开 3×3 合成界面
3. **Given** 3×3 合成界面打开，**When** 玩家按 ESC 或 E 键，**Then** 合成界面关闭，合成格中的物品返还到物品栏
4. **Given** 玩家在 3×3 合成格中按木镐配方放置材料（3 木板 + 2 木棍），**When** 玩家点击输出格，**Then** 获得 1 个木镐，材料消耗

---

### User Story 3 - 工具制作与使用 (Priority: P1)

玩家可以制作不同等级和类型的工具，工具影响挖掘速度，并且有耐久度限制。

**Why this priority**: 工具是游戏核心玩法，直接影响玩家的挖掘效率和游戏体验。

**Independent Test**: 可以通过制作木镐、使用木镐挖掘石头、观察挖掘速度提升和耐久度消耗来测试。

**Acceptance Scenarios**:

1. **Given** 玩家手持木镐，**When** 玩家挖掘石头方块，**Then** 挖掘速度比空手快 2 倍
2. **Given** 玩家手持石镐，**When** 玩家挖掘石头方块，**Then** 挖掘速度比木镐快
3. **Given** 玩家手持镐子挖掘方块，**When** 方块被破坏，**Then** 镐子耐久度减少 1 点
4. **Given** 工具耐久度降为 0，**When** 玩家继续使用该工具，**Then** 工具损坏消失，播放损坏音效
5. **Given** 玩家手持斧头，**When** 玩家挖掘木头方块，**Then** 挖掘速度比空手快，但挖掘石头时无加速效果

---

### User Story 4 - 熔炉放置与冶炼 (Priority: P2)

玩家可以放置熔炉方块，使用燃料冶炼矿石或烹饪食物。

**Why this priority**: 熔炉是获取高级材料（如铁锭）的必要设施，但可以在基础工具系统完成后再实现。

**Independent Test**: 可以通过放置熔炉、添加燃料和原料、等待冶炼完成、获取产物来测试。

**Acceptance Scenarios**:

1. **Given** 玩家手持熔炉方块，**When** 玩家对着地面右键点击，**Then** 熔炉方块放置在目标位置
2. **Given** 世界中存在熔炉方块，**When** 玩家对准熔炉右键点击，**Then** 打开熔炉界面（燃料槽 + 输入槽 + 输出槽 + 进度条）
3. **Given** 熔炉界面打开且输入槽有铁矿石、燃料槽有煤炭，**When** 等待冶炼完成，**Then** 输出槽出现铁锭，进度条显示冶炼进度
4. **Given** 熔炉正在冶炼，**When** 玩家关闭熔炉界面，**Then** 冶炼过程继续进行
5. **Given** 燃料耗尽，**When** 冶炼未完成，**Then** 冶炼暂停，进度条停止，添加燃料后继续

---

### User Story 5 - 配方系统 (Priority: P2)

游戏支持形状配方和无形状配方，玩家可以通过正确摆放材料来合成物品。

**Why this priority**: 配方系统是合成功能的核心逻辑，需要在 UI 完成后实现具体配方匹配。

**Independent Test**: 可以通过测试不同配方（形状/无形状）的匹配逻辑来验证。

**Acceptance Scenarios**:

1. **Given** 玩家在合成格中按木镐形状放置材料，**When** 配方匹配，**Then** 输出格显示木镐
2. **Given** 玩家在合成格中放置材料但位置偏移，**When** 形状相对位置正确，**Then** 配方仍然匹配
3. **Given** 无形状配方（如木板→木棍），**When** 材料放在任意位置，**Then** 只要数量和类型正确即可匹配

---

### Edge Cases

- 合成格中的物品在关闭界面时如何处理？→ 返还到物品栏，物品栏满则掉落为物品实体
- 工具耐久度为 0 时正在挖掘怎么办？→ 立即中断挖掘，工具消失
- 熔炉被破坏时内部物品如何处理？→ 所有物品掉落为物品实体
- 合成输出格物品无法放入物品栏（已满）怎么办？→ 不允许点击取出，提示物品栏已满
- 玩家同时打开多个熔炉界面？→ 同一时间只能打开一个交互界面

## Requirements *(mandatory)*

### Functional Requirements

**合成系统核心**
- **FR-001**: 系统 MUST 在物品栏界面中提供 2×2 合成格
- **FR-002**: 系统 MUST 支持工作台方块提供的 3×3 合成格
- **FR-003**: 系统 MUST 支持形状配方匹配（材料位置相对关系必须正确）
- **FR-004**: 系统 MUST 支持无形状配方匹配（只检查材料类型和数量）
- **FR-005**: 系统 MUST 在配方匹配时实时显示输出物品预览
- **FR-006**: 系统 MUST 在玩家取走输出物品时消耗对应材料

**工作台方块**
- **FR-007**: 系统 MUST 允许玩家放置和破坏工作台方块
- **FR-008**: 系统 MUST 在玩家右键点击工作台时打开 3×3 合成界面
- **FR-009**: 工作台方块 MUST 有独特的纹理外观

**工具系统**
- **FR-010**: 系统 MUST 支持 4 个工具等级：木质、石质、铁质、钻石
- **FR-011**: 系统 MUST 支持 5 种工具类型：镐、斧、锹、剑、锄
- **FR-012**: 系统 MUST 根据工具类型和等级计算挖掘速度加成，适配关系为：镐→石类方块、斧→木类方块、锹→土/沙类方块；不适配的工具无加速效果
- **FR-013**: 系统 MUST 为每个工具维护耐久度值
- **FR-014**: 系统 MUST 在工具使用时减少耐久度
- **FR-015**: 系统 MUST 在耐久度归零时销毁工具
- **FR-016**: 系统 MUST 在 UI 中显示工具当前耐久度

**熔炉系统**
- **FR-017**: 系统 MUST 允许玩家放置和破坏熔炉方块
- **FR-018**: 系统 MUST 在玩家右键点击熔炉时打开熔炉界面
- **FR-019**: 熔炉界面 MUST 包含燃料槽、输入槽、输出槽和进度条
- **FR-020**: 系统 MUST 支持煤炭（80秒）、木炭（80秒）、木板（15秒）、原木（15秒）作为燃料
- **FR-021**: 系统 MUST 在有燃料和输入物品时自动开始冶炼
- **FR-022**: 系统 MUST 显示冶炼进度条动画
- **FR-023**: 熔炉 MUST 在界面关闭后继续冶炼过程

**配方定义**
- **FR-024**: 系统 MUST 支持配方注册机制
- **FR-025**: 系统 MUST 包含基础配方：原木→木板、木板→木棍、木板→工作台
- **FR-026**: 系统 MUST 包含工具配方：木/石/铁/钻石 × 镐/斧/锹/剑/锄
- **FR-027**: 系统 MUST 包含熔炉配方：圆石→熔炉

**UI 交互**
- **FR-028**: 合成界面 MUST 支持物品拖拽放置
- **FR-029**: 系统 MUST 在关闭合成界面时将未取走的物品返还物品栏
- **FR-030**: 系统 MUST 在物品栏已满时将物品掉落为物品实体

### Key Entities

- **CraftingRecipe**: 合成配方实体，包含配方类型（形状/无形状）、输入材料列表、输出物品、合成格尺寸要求
- **Tool**: 工具实体，包含工具类型、材质等级、当前耐久度、最大耐久度、挖掘速度倍率
- **Furnace**: 熔炉实体，包含燃料槽、输入槽、输出槽、当前燃烧时间、冶炼进度
- **SmeltingRecipe**: 冶炼配方实体，包含输入物品、输出物品、冶炼时间
- **FuelItem**: 燃料物品实体，包含燃烧时间值

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 玩家可以在 30 秒内完成从原木到木镐的完整合成流程
- **SC-002**: 工具挖掘速度加成明显可感知，各等级倍率为：木质2x、石质4x、铁质6x、钻石8x
- **SC-003**: 工具耐久度系统正常工作，各等级耐久度为：木质60、石质131、铁质250、钻石1561
- **SC-004**: 熔炉冶炼一个物品的时间为 10 秒
- **SC-005**: 合成界面响应流畅，物品拖拽无明显延迟
- **SC-006**: 所有基础配方（木板、木棍、工作台、基础工具、熔炉）均可正常合成
- **SC-007**: 玩家可以同时运行多个熔炉独立冶炼

## Assumptions

- 当前项目已有完整的物品栏系统（36 格背包 + 拖拽交互）
- 当前项目已有方块放置和破坏机制
- 当前项目已有右键交互检测机制
- 当前项目已有物品实体掉落系统
- 矿石方块（铁矿石、钻石矿石等）将在后续功能中添加
- 工具攻击伤害加成将在后续战斗系统中实现

## Out of Scope

- 附魔系统
- 铁砧修复工具
- 矿石方块生成（需要单独的矿石生成功能）
- 工具攻击伤害加成
- 合成配方书/提示系统
- 自动合成
