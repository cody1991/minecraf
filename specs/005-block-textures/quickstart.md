# Quickstart: 更多方块与纹理

**Feature**: 005-block-textures  
**Date**: 2025-12-12

## 概述

本功能为 WebCraft 添加真实纹理贴图和更多方块类型，替代当前的纯色渲染。

## 前置条件

- Node.js 18+
- 现代浏览器（Chrome/Firefox/Safari，支持 WebGL 2.0）

## 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev

# 3. 打开浏览器访问
# http://localhost:5173
```

## 功能验证

### 1. 纹理渲染验证

启动游戏后，观察地形中的方块：
- ✅ 草方块顶面显示绿色草地纹理
- ✅ 草方块侧面显示带草边的泥土纹理
- ✅ 石头、泥土等方块显示对应纹理

### 2. 新方块类型验证

按数字键 1-0 切换方块类型：
| 按键 | 方块 |
|------|------|
| 1 | 草地 |
| 2 | 泥土 |
| 3 | 石头 |
| 4 | 木头 |
| 5 | 沙子 |
| 6 | 圆石 |
| 7 | 砖块 |
| 8 | 玻璃 |
| 9 | 树叶 |
| 0 | 原木 |

### 3. 透明方块验证

放置玻璃或水方块：
- ✅ 玻璃方块透明，可看到后面的方块
- ✅ 水方块半透明，有蓝色色调

### 4. 方块选择器 UI 验证

查看屏幕底部的方块选择器：
- ✅ 每个槽位显示对应方块的纹理预览
- ✅ 当前选中的方块有高亮边框

## 纹理资源

纹理图集位于 `public/textures/blocks.png`：
- 尺寸：256x48 像素
- 布局：16 列 × 3 行
- 行 1：顶面纹理
- 行 2：侧面纹理
- 行 3：底面纹理

## 性能检查

打开浏览器开发者工具 (F12) → Performance 标签：
- 目标帧率：30+ FPS（移动端）/ 60 FPS（桌面端）
- 检查 Draw Call 数量应与纯色渲染相当

## 故障排除

### 纹理显示为纯色

1. 检查 `public/textures/blocks.png` 是否存在
2. 检查浏览器控制台是否有加载错误
3. 纹理加载失败时会自动回退到纯色

### 透明方块渲染异常

1. 确认使用的是支持 WebGL 2.0 的浏览器
2. 检查 GPU 驱动是否最新
