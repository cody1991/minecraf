# Research: 更新操作面板

**Date**: 2025-12-13  
**Feature**: 001-update-controls-panel

## Summary

本功能为简单的 HTML 内容更新，无需深度技术研究。以下记录已确认的技术细节。

## 已确认的技术细节

### 目标文件位置

- **Decision**: `index.html` 第 148-157 行的 `#instructions` 元素
- **Rationale**: 通过代码分析确认，操作说明面板位于此处
- **Alternatives considered**: 无

### 当前操作命令完整列表

通过代码分析（`InputManager.ts`, `KeyboardInput.ts`, `MouseInput.ts`）确认的所有操作：

| 类别 | 按键/操作 | 功能 |
|------|-----------|------|
| 移动控制 | W/↑ | 向前移动 |
| 移动控制 | S/↓ | 向后移动 |
| 移动控制 | A/← | 向左移动 |
| 移动控制 | D/→ | 向右移动 |
| 移动控制 | Space | 跳跃（陆地）/ 上浮（水中）|
| 移动控制 | Shift | 冲刺（陆地）/ 下潜（水中）|
| 鼠标操作 | 鼠标移动 | 视角控制 |
| 鼠标操作 | 左键 | 破坏方块 |
| 鼠标操作 | 右键 | 放置方块 |
| 方块选择 | 1-9 | 选择第 1-9 个方块 |
| 方块选择 | 0 | 选择第 10 个方块 |
| 方块选择 | Tab | 循环切换方块 |
| 功能键 | M | 打开/关闭世界地图 |
| 功能键 | V | 切换第一/第三人称视角 |
| 功能键 | C | 打开角色选择界面 |
| 其他 | ESC | 解锁鼠标 / 关闭地图 |

### 当前面板问题

- **Decision**: 当前面板显示 "1-5 - 切换方块"，但实际支持 1-9 和 0（共 10 个）
- **Rationale**: 代码中 `KeyboardInput.ts` 第 27-30 行明确处理 1-9 和 0 键
- **Alternatives considered**: 无

### 缺失的操作说明

当前面板缺少以下操作：
1. Tab 循环切换方块
2. V 切换视角
3. C 角色选择
4. 水中特殊控制（Space 上浮、Shift 下潜）
5. 方向键移动
