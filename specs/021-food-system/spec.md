# Feature Specification: 食物系统

**Feature Branch**: `021-food-system`  
**Created**: 2025-12-16  
**Status**: Draft  
**Input**: User description: "020a - 食物系统 - 添加食物物品类型、玩家攻击动物、动物死亡掉落食物、右键吃食物恢复饥饿值"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 攻击动物获取食物 (Priority: P1)

玩家在游戏世界中遇到动物（牛、猪、羊、鸡、兔子），通过左键点击攻击动物。动物受到伤害后会有视觉反馈（红色闪烁），当生命值归零时动物死亡并在原地掉落对应的食物物品。

**Why this priority**: 这是整个食物系统的核心流程起点。没有攻击和掉落机制，后续的拾取和食用都无法进行。

**Independent Test**: 可以通过攻击任意动物直到死亡，验证是否掉落对应食物物品来独立测试。

**Acceptance Scenarios**:

1. **Given** 玩家面前有一只牛, **When** 玩家左键点击攻击牛, **Then** 牛受到伤害并显示红色闪烁效果
2. **Given** 动物生命值归零, **When** 动物死亡, **Then** 动物消失并在原位置生成对应的食物掉落物
3. **Given** 玩家攻击狼或狐狸, **When** 动物死亡, **Then** 不掉落任何食物（狼和狐狸不掉落食物）

---

### User Story 2 - 拾取食物到物品栏 (Priority: P2)

玩家靠近地面上的食物掉落物时，食物自动被拾取并添加到玩家的物品栏中。拾取时播放拾取音效，食物显示在快捷栏或背包中。

**Why this priority**: 拾取是连接"获取食物"和"使用食物"的桥梁，是完整流程的必要环节。

**Independent Test**: 可以通过接近地面上的食物掉落物，验证是否自动拾取并显示在物品栏中。

**Acceptance Scenarios**:

1. **Given** 地面上有食物掉落物, **When** 玩家走近（距离小于拾取范围）, **Then** 食物自动添加到物品栏并播放拾取音效
2. **Given** 玩家物品栏已有同类型食物（未满堆叠上限）, **When** 拾取同类型食物, **Then** 食物数量堆叠增加
3. **Given** 玩家物品栏已满, **When** 玩家靠近食物掉落物, **Then** 食物保留在地面上不被拾取

---

### User Story 3 - 食用食物恢复饥饿值 (Priority: P3)

玩家选中快捷栏中的食物，按住右键进食。进食需要一定时间，完成后恢复对应的饥饿值，同时消耗一个食物物品。

**Why this priority**: 食用是食物系统的最终目的，让玩家能够通过食物恢复饥饿值，形成完整的生存循环。

**Independent Test**: 可以通过选中食物并右键食用，验证饥饿值是否恢复且食物数量减少。

**Acceptance Scenarios**:

1. **Given** 玩家快捷栏选中食物且饥饿值未满, **When** 玩家按住右键, **Then** 开始进食动作（显示进食进度）
2. **Given** 玩家正在进食, **When** 进食完成, **Then** 恢复对应饥饿值，食物数量减1
3. **Given** 玩家饥饿值已满（10格）, **When** 玩家尝试食用食物, **Then** 无法进食（饥饿值已满时不能吃东西）
4. **Given** 玩家正在进食, **When** 玩家松开右键或移动, **Then** 进食中断，不消耗食物也不恢复饥饿值

---

### Edge Cases

- 玩家在水中攻击动物时，攻击判定是否正常工作？
- 食物掉落在水中或岩浆中时如何处理？（水中正常存在，岩浆中销毁）
- 动物在被攻击后逃跑，玩家需要追击才能击杀
- 多个食物掉落物重叠时，拾取顺序如何处理？（按生成顺序）
- 玩家死亡后，地面上的食物掉落物是否保留？（保留）

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统必须支持玩家通过左键点击攻击动物，每次攻击造成固定伤害
- **FR-002**: 系统必须在动物受到伤害时显示红色闪烁视觉反馈
- **FR-003**: 系统必须在动物死亡时在其位置生成对应的食物掉落物
- **FR-004**: 系统必须支持5种食物类型：生牛肉、生猪排、生羊肉、生鸡肉、生兔肉
- **FR-005**: 系统必须在玩家接近食物掉落物时自动拾取到物品栏
- **FR-006**: 系统必须支持食物在物品栏中堆叠（最大64个）
- **FR-007**: 系统必须支持玩家通过按住右键食用选中的食物
- **FR-008**: 系统必须在进食完成后恢复对应的饥饿值并消耗1个食物
- **FR-009**: 系统必须阻止饥饿值已满时的进食行为
- **FR-010**: 系统必须在进食被中断时取消进食且不消耗食物
- **FR-011**: 系统必须为食物物品显示独特的图标/纹理
- **FR-012**: 系统必须播放攻击音效、拾取音效和进食音效

### Key Entities

- **食物物品 (Food Item)**: 可被拾取和食用的物品，包含类型、名称、饥饿恢复值
- **食物掉落物 (Food Drop)**: 世界中可见的3D物品实体，可被玩家拾取
- **攻击判定 (Attack Detection)**: 检测玩家攻击方向与动物的碰撞
- **进食状态 (Eating State)**: 跟踪玩家的进食进度和目标食物

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 玩家能在3秒内完成一次完整的"攻击动物→拾取食物→食用恢复"流程
- **SC-002**: 所有5种动物（牛、猪、羊、鸡、兔子）死亡后100%掉落对应食物
- **SC-003**: 食物拾取在玩家进入拾取范围后0.5秒内完成
- **SC-004**: 进食动作在1.5秒内完成（与Minecraft原版一致）
- **SC-005**: 不同食物恢复不同饥饿值（生鸡肉/生羊肉恢复2格，其他生肉恢复3格）
- **SC-006**: 玩家能够直观地识别快捷栏中的食物物品

## Assumptions

- 攻击伤害值暂定为每次攻击3点（后续工具系统会调整）
- 攻击距离为3格（与方块交互距离一致）
- 拾取范围为2格
- 进食时间为1.5秒
- 食物掉落物在世界中存在5分钟后自动消失
- 食物掉落物受重力影响会落到地面
- 狼和狐狸不掉落食物（已在现有代码中配置）
